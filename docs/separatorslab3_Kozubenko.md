**Markdown** — это стандарт де-факто для написания документации в мире ИТ. Созданный в 2004 году *Джоном Грубером* и Аароном Шварцем, он задумывался как максимально простой способ форматирования, который не мешает чтению самого текста.
***
Язык разметки позволяет быстро оформлять структуру и элементы текста с помощью обычных символов:
- Заголовки: Создаются с помощью символа решётки (#).
- Выделение текста: Текст можно сделать курсивом (окружив его звёздочками *текст*) или жирным (двумя звёздочками **текст**).
- Списки: Маркированные списки создаются с помощью дефиса (-) или звёздочки (*), а нумерованные — обычными цифрами с точкой (1.).
- Ссылки и изображения: Кликабельные ссылки записываются как [Текст](URL). Изображения вставляются аналогично, но перед ними ставится восклицательный знак: ![Описание](ссылка_на_фото).
- Код и цитаты: Короткий внутристрочный код выделяется backticks (обратными апострофами `код`), а блоки кода — тремя такими символами (```). Для цитат используется символ >.
___
Пример форматирования кода:
```python
print("Hello, Markdown!")
```
